## Overview
Hello-Agents is a comprehensive, from-scratch guide to building intelligent agent systems, balancing theoretical knowledge with practical implementation. It differentiates between software engineering agents and AI-native agents, aiming to transform users into system builders by mastering concepts like planning, memory, and agentic reasoning.

## Key Concepts
*   **Agent Classification:** Distinguishing between Software Engineering Agents (process-driven, e.g., Dify) and AI-Native Agents (AI-driven systems).
*   **Core Paradigms:** Understanding foundational agent methodologies such as ReAct (Reasoning-Action-Observation), Plan-and-Solve, and Reflection for structured execution.
*   **Framework Ecosystem:** Exploration of existing frameworks (AutoGen, LangGraph) alongside the ability to build custom frameworks from scratch using APIs.
*   **Memory & Context Engineering:** Implementing robust systems for memory management (short-term, long-term, RAG) and managing contextual understanding through advanced prompt engineering.
*   **Agentic Learning:** Practical application of Reinforcement Learning techniques (SFT to GRPO) for training agent behaviors.
*   **Inter-Agent Communication:** Understanding protocols necessary for multiple agents to interact effectively (e.g., MCP, A2A).

## Key Insights
*   **Holistic Learning Path:** The guide provides a structured progression from fundamental LLM knowledge and classical paradigms to advanced system architecture and real-world deployment.
*   **Practical Skill Development:** Learners gain the ability to implement agent systems using both low-code platforms and custom code frameworks, fostering true system design skills.
*   **Depth in Advanced Topics:** The curriculum deeply explores critical areas often overlooked, such as memory management (RAG), context handling, and formal training methods for agents.
*   **Community Focus:** The project is driven by the Datawhale community, offering extensive practical examples, open-source resources, and job market preparation materials.
*   **Real-World Application:** The guide connects theoretical concepts directly to complex projects (e.g., intelligent travel assistants, social simulations), demonstrating tangible engineering value.
